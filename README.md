# TypeProlog
TypeProlog - исследовательский проект по **логическому программированию** в **теории типов**.

Реализация зависимого типизированного лямбда-исчисления и использование логического программирования для **поиска термов определённого типа**.

### Цели и задачи на данный момент
- Написать **минимальное доверенное ядро** (minimal trusted kernel), в которое входит определение термов и типов, редукция и проверка типов.
- Написать **простой язык программирования**, который дешугарится в термы ядра(лексер, парсер, дешугар).
- Написать алгоритм поиска термов определённого типа на основе **обратного перебора** способов получения этого типа(Prolog-подобный алгоритм).
- Сделай **простой REPL** для языка и использования логического программирования.
- Изложить все это в **Доп. Материалах**
- Написать **примеры использования** данного продукта

### Установка
```bash
git clone https://github.com/MaximVossin/TypeProlog.git
cd TypeProlog
cd src
cargo build --realise
```
Также добавить ```tpi``` и ```tp-repl``` в PATH

### Использование (планируемое)
Интерпретация языка TypeProlog - 
```tpi File.tp``` <br>
Получение термов TypeProlog -
```tpi File.tp --only-term``` <br>
Запуск REPL -
```tp-repl``` <br>

### Команды REPL
| Команда | Действие |
|---------|----------|
| ```:?``` | справка по всем командам |
| ```:l File.tp/:load``` | загрузить File.tp |
| ```:r File.tp/:reload``` | перезагрузить File.tp (после правок в файле) |
| ```:t function/:type``` | выдать тип функции(леммы) |
| ```:c type/:constructors``` | выдать все конструкторы типа |
| ```:p type/:proof``` | построить автоматически с помощью логического программирования |
| ```:q/:quit``` | выход |
