# Ядро
### Бестиповое исчисление
Терм это одна из следующих конструкций:
- пустой терм,
- ```λx. T```,
- ```T1 T2```,
- ```let x = T; T1```,
- ```V T1```
- ```case T of { C1 => T1, C2 => T2, ...}```

где T, T1, T2 - **термы**, C1, C2 - **конструкторы** (строгое определение конструкторов будет далее), V - определённая **переменная** (также допустима сама переменная - рекурсия).

В качестве вычисления используется **βδζι-редукция**. <br>
```(λx. T) y -> λx. T[x/y]``` при условии, что если y связанная переменная в самом терме, то T не содержит case of по x, тогда называется **β-редукция** <br>
```let x = T; ... x -> let x = T; ... T``` называется **δ-редукция** <br>
```let x = T; ... -> ... ``` при условии что в ... x не встречается называется **ζ-редукция** <br>
```case S ... of {...; S ... => T1} -> T1 ``` называется **ι-редукция**.

Алгоритм редукции:
- Найти самый левый βδζι-редекс (**ленивая стратегия**)
- Применить к нему соответствующее правило
- Повторить, пока редексов не останется (**нормальная форма**)

Данное бестиповое исчисление **эквиалентно машине Тьюринга** при правильных конструкторах. И соответственно существует термы, которые **не имеют нормальной формы**. Например ```(λx. x x) (λx. x x)``` не имеет **нормальной формы** (известен как Ω-комбинатор). Для гарантированности сильной нормализованности мы потребуем того что рекурсия должна быть структурной (**аргументы структурно меньше**, в случаи нескольких аргументов - **лексиграфический порядок**). Так как длина терма это натуральные числа с нулём, а длина **всегда уменьшается**, то вычисление автоматически **завершается**.
